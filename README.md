# חוקר התנ״ך

מערכת מחקר לתנ״ך המלא: חיפוש ראשי וסופי תיבות, ראשי וסופי פסוקים, דילוגים קבועים ומשתנים, חיפוש לפי ניקוד,
גימטריית ניקוד, 24 שיטות גימטריה, חילופי אותיות, חיפוש משולב רב־שלבי וניתוח סטטיסטי של אותיות וניקוד.
המערכת כוללת ממשק משתמש מלא בעברית.

> **הטקסט:** ״מקרא על פי המסורה״ (MAM) של אבי קדיש, מבוסס על כתר ארם צובא, כולל ניקוד, טעמים, קרי וכתיב,
> פרשות פתוחות וסתומות ואותיות גדולות, קטנות ותלויות.
> מקור: [ויקיטקסט — מקרא על פי המסורה](https://he.wikisource.org/wiki/%D7%9E%D7%A7%D7%A8%D7%90_%D7%A2%D7%9C_%D7%A4%D7%99_%D7%94%D7%9E%D7%A1%D7%95%D7%A8%D7%94),
> רישיון CC BY-SA 4.0, דרך מאגר [`bdenckla/MAM-basics`](https://github.com/bdenckla/MAM-basics) (MAM-simple JSON).

## התקנה והפעלה

נדרש Python 3.11 ומעלה, וחיבור לאינטרנט בהפעלה הראשונה (להורדת הטקסט).

```bash
python -m venv .venv
```

```bash
.venv/Scripts/python -m pip install -r requirements.txt
```

```bash
.venv/Scripts/python -m tanakh_explorer setup
```

```bash
.venv/Scripts/python -m tanakh_explorer serve
```

לאחר מכן פתחו את הדפדפן בכתובת http://127.0.0.1:8000. ב־Windows אפשר גם להפעיל בלחיצה כפולה את `start.bat`,
שמבצע את כל השלבים ופותח את הדפדפן כשהשרת מוכן.

**אייקון על שולחן העבודה (Windows):** הפקודה הבאה יוצרת קיצור דרך בשם ״חוקר התנ״ך״, עם אייקון התוכנה:

```bash
powershell -ExecutionPolicy Bypass -File tools/create_shortcut.ps1
```

לחיצה כפולה על האייקון מפעילה את השרת בחלון ממוזער ופותחת את הדפדפן. כדי לעצור את השרת סוגרים את החלון
הממוזער. אם השרת כבר פועל, לחיצה נוספת רק פותחת את הדפדפן.

הפקודה `setup` מורידה את קובצי המקור מגרסה נעולה (pinned commit), מחשבת לכל קובץ גיבוב SHA-256, בונה את מסד
הנתונים (`data/build/corpus.sqlite`) ומריצה את מערכת האימות. ב־Linux/macOS השתמשו ב־`.venv/bin/python` במקום
`.venv/Scripts/python`.

פקודות נוספות: `download`, `build`, `validate`, `bench` (מדידת ביצועים).

## מה יש במערכת

| עמוד | תוכן |
|---|---|
| 1. חיפוש ראשי תיבות | ראשי מילים, סופי מילים, חיפוש מעורב (ראש או סוף לכל אות), מילה שלמה, רצף אותיות, ביטוי; קבוצות אותיות לפי מוצאות הפה; **חיפוש בכל סידורי האותיות (קומבינטוריקה)** עם טבלת הופעות לכל סידור |
| 2. חיפוש פסוקים | ראשי וסופי פסוקים, ברצף או בדילוג, וגם בכל סידורי האותיות |
| 3. חיפוש דילוגים | דילוג קבוע או משתנה במילים, בפסוקים או באותיות; דילוג מנקודת התחלה; **״חפש בכל אפשרויות הדילוג״** כמשימת רקע עם התקדמות, ביטול וחידוש |
| 4. חיפוש ניקוד | ניתוח חתימת הניקוד של מילה מנוקדת וחיפושה בראשי או בסופי מילים ופסוקים, בראשי כל המילים בפסוק (התאמה מלאה או חלקית), במילה שלמה או ברצף אותיות; התאמה לפי ניקוד בלבד, אותיות וניקוד, או ערכים לפי הסדר |
| 5. גימטריית ניקוד | מילים, רצפי ראשים או סופים, ושמונה סוגי חיפוש בתוך פסוק; **ניקוד מול ניקוד** ו**ניקוד מול אותיות** מוצגים בנפרד |
| 6. כל סוגי הגימטריה | מחשבון עם הצגת שלבי החישוב, חיפוש לפי ערך או מספר (מילה, n מילים, פסוק שלם), **״חיפוש בכל סוגי הגימטריה״**, ושיטות מותאמות אישית |
| 7. חילופי אותיות | 11 שיטות, כולל הזזה בכל מספר מקומות; **״בדוק את כל ההזזות״**, **״חפש בכל שיטות חילופי האותיות״**, **״חפש בכל הגימטריות והחילופים״** |
| 8. בניית חיפוש משולב | שרשור שלבים עם סוגי קלט ופלט מוגדרים ובדיקת התאמה ביניהם, ומעקב מלא שאפשר לשחזר |
| 9. ניתוח אותיות וניקוד | **סיכום ניקוד לאות**: כותבים אות אחת ומקבלים את כל התנועות שמופיעות עליה בתחום שנבחר (מספר מופעים, אחוז, סכום הניקוד, פירוט לפי ספר). בנוסף: טבלת כל האותיות × כל התנועות לכל תחום ולכל מיקום במילה; לחיצה על מספר מציגה את המופעים ואת ההתפלגות לפי ספר ומיקום; השוואה בין שני תחומים |
| 10. קורא תנ״ך | ניקוד, טעמים, קרי וכתיב, פרשות, אותיות מיוחדות, וניתוח מפורט של כל אות (כולל שכבת תגין לפי הכלל) |
| 11. תקינות הנתונים | דוח האימות המלא, עם אפשרות להריץ אותו מחדש |
| 12. היסטוריית חיפושים | כל חיפוש נשמר עם ההגדרות והתוצאות, וניתן לייצא אותו בכל הפורמטים |

**ייצוא:** ליד כל תוצאה בממשק (חיפושים, סריקות, טבלאות סטטיסטיקה, חיפוש משולב, היסטוריה) יש כפתור ״ייצוא״,
שמייצא ל־**Excel, CSV, HTML** (להדפסה או לשמירה כ־PDF), **JSON, Markdown** ו**טקסט**. בראש כל קובץ מופיע מידע על
החיפוש: סוג החיפוש, השאילתה, כל ההגדרות (נוסח, מקף, אותיות סופיות, תחום, דילוגים, גבולות, שיטה, סוג התאמה), מספר
התוצאות הכולל ומספר התוצאות בקובץ, זמן החיפוש וזמן הייצוא, ומקור הטקסט ורישיונו. בפסוקים שבקובץ מסומנות האותיות
שנמצאו. האפשרות ״כל התוצאות״ מריצה את החיפוש מחדש וכוללת עד 5,000 תוצאות. אם הקובץ חלקי, הדבר מצוין בראשו.

ליד כל כפתור, מושג ואפשרות בממשק מופיע סימן ⓘ. נגיעה בו (או לחיצה) פותחת הסבר, כולל הסבר לכל אחת מהאפשרויות
ברשימה. במחשב, ריחוף מעל כפתור מציג את ההסבר כחלונית קטנה.

בכל עמוד אפשר לבחור **תחום**: כל התנ״ך, תורה, נביאים או כתובים, ספר (לפי 24 הספרים או לפי חלוקת הדפוס), פרשת
שבוע, פרשה פתוחה או סתומה, טווח פרקים, טווח פסוקים, או צירוף של כמה תחומים. בראש המסך בוחרים **נוסח לחישוב**
(כתיב או קרי), **מקף** (מפריד בין מילים, או צירוף במקף כמילה אחת) ו**אותיות סופיות** (ם=מ או התאמה מדויקת).

## עקרונות הדיוק

* **רק אותיות אמיתיות נספרות.** סימוני פ/ס של פרשות, מספרי פרקים ופסוקים, כותרות, ניקוד, טעמים, מקף, סוף פסוק,
  פסק ותגין אינם נספרים כאותיות. סימוני הפרשות מזוהים לפי מבנה הנתונים ולא על ידי מחיקת אותיות. פ או ס שבתוך
  מילה הן אותיות רגילות.
* **קרי וכתיב** אינם מחוברים לעולם כשתי מילים עוקבות. כל חיפוש רץ על אחד מהם, והבחירה נשמרת עם התוצאה.
* **ניקוד** נשאר משויך לאות שלו. סימנים אינם מועברים בין אותיות. מקרה שאינו חד־משמעי מסומן לבדיקה ואינו מסווג.
* **שקיפות:** לכל תוצאה אפשר לפתוח ״הצג כיצד חושבה התוצאה״, וכל הגדרות החיפוש נשמרות.
* **סריקות:** תוצאה חלקית לעולם אינה מוצגת כסריקה מלאה. לפני סריקה מוצג אומדן להיקף החיפוש.
* **שיטות מסורתיות מול שיטות אחרות:** לכל שיטה מצוינים מקור וקטגוריה (מסורתית, מתמטית, טבלת החוקר, מותאמת
  אישית, הגדרת המשתמש).

## מבנה הקוד

```
tanakh_explorer/
  hebrew.py            Unicode: אותיות, סופיות, סימנים
  niqqud.py            פירוק ניקוד לאותיות וסיווג תנועות (כולל שורוק)
  niqqud_gematria.py   טבלת גימטריית הניקוד
  importers/           הורדה עם SHA-256, קורא MAM-simple, קורא WLC
  corpus/              מבנה הנתונים, שכבות כתיב/קרי ומקף, SQLite, תחומים, פרשות, קורא
  gematria/            Gematria Engine: מנוע ורישום שיטות, טבלאות מילוי ושמות מספרים, שיטות מותאמות אישית
  transformations/     Hebrew Letter Transformations Engine
  search/              מנוע מיקומים מאוחד, שירותי חיפוש, סריקות, עיצוב תוצאות
  combined/            Advanced Search Builder
  stats/               ניתוח אותיות וניקוד
  validation/          בדיקות שלמות
  api/                 FastAPI, היסטוריה, משימות רקע
  frontend/            ממשק עברי (HTML/CSS/JS, ללא שלב בנייה); help.js — ההסברים לכל רכיב בממשק
tools/                 יצירת האייקון וקיצור הדרך לשולחן העבודה
tests/                 pytest: יחידה, השוואה למימושי ייחוס פשוטים, והתנ״ך המלא
docs/                  תיעוד
```
