# שיטות חילופי האותיות
המסמך נוצר אוטומטית מקוד המערכת (`tanakh_explorer/transformations/methods.py`).
חילוף הוא פעולת טקסט → טקסט. הניקוד נשאר במקומו (על אותו מיקום), נקודות שין/שׂין מושמטות כשהאות אינה ש.

## א״ת ב״ש

- **מקור:** מתועד במקרא עצמו לפי חז״ל (״ששך״ = בבל, ירמיהו כה, כו; רש״י שם) ובברייתא דל״ב מידות.
- **מדיניות אותיות סופיות (ברירת מחדל):** normalize · **החלפה הדדית:** כן
- **הגדרות:** `finals` — אותיות סופיות בקלט; `output_finals` — צורת אותיות בפלט

## הזזת אותיות (כל מספר מקומות)
- **מזהה:** `shift` · **שם לועזי:** Letter shift · **קטגוריה:** מסורתית מתועדת
- **תיאור:** כל אות עוברת n מקומות קדימה או אחורה באלף־בית. הזזה קדימה באחת היא אבג״ד (א→ב, ב→ג …).
- **מקור:** ״אבג״ד״ מנוי בין צירופי האותיות; ההזזה הכללית היא הכללה מתמטית שלו.
- **מדיניות אותיות סופיות (ברירת מחדל):** keep · **החלפה הדדית:** לא
- **הגדרות:** `n` — מספר מקומות; `direction` — כיוון; `cyclic` — מחזורי (ת→א / א→ת); `edge` — בהזזה לא מחזורית, אות שעוברת את הקצה; `finals` — אותיות סופיות; `output_finals` — צורת אותיות בפלט

## חילופי מוצאות הפה

לפי ספר יצירה (ב, ג): אותיות הגרון — אחהע; אותיות השפתיים — בומפ; אותיות החיך — גיכק; אותיות הלשון — דטלנת; אותיות השיניים — זסשרצ. אין מיפוי אחד־לאחד מתועד בתוך קבוצה, ולכן המערכת מממשת זאת כהתאמה: אות בשאילתה מתאימה לכל אות מקבוצתה (״קבוצות אותיות״ בחיפוש). מיפוי אחר אפשר להגדיר ב״מיפוי אותיות מותאם״ בחיפוש המשולב.
