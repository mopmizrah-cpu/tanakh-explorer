# שיטות הגימטריה
המסמך נוצר אוטומטית מקוד המערכת (`tanakh_explorer/gematria/methods.py`).
כל שיטה מוגדרת כיחידה עצמאית עם מזהה ייחודי. הוספת שיטה אינה דורשת שינוי במנוע החיפוש.
סדר הפעולות בכל שיטה: (1) ערכי אותיות → (2) שקלול מיקום (אם יש) → (3) עיבוד הסכום (אם יש).

## גימטריה רגילה (מספר הכרחי)
- **מזהה:** `standard` · **שם לועזי:** Mispar Hechrachi · **קטגוריה:** מסורתית מתועדת
- **נוסחה:** כל אות לפי ערכה: א=1 … ט=9, י=10 … צ=90, ק=100 … ת=400; סכום הערכים.
- **מקור:** השיטה הבסיסית, מתועדת כבר במשנה (אבות ג, יח: ״גימטריאות — פרפראות לחכמה״) ובברייתא דל״ב מידות.
- **אותיות סופיות:** אותיות סופיות מקבלות את ערך האות הרגילה (ך=20, ם=40, ן=50, ף=80, ץ=90).
- **דוגמה:** שלום = 376
